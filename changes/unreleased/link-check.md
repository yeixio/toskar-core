### Added

- Check links in answers, in Settings (off by default): after an answer is written, Toskar asks each site it links to, up to six, whether the page opens, and names the links that didn't under the answer. A page that's gone, or a site that doesn't exist, counts as dead; a sign-in, a limit, or a slow site doesn't, and nothing counts as dead when no site answered, as when this computer is offline. Each check is listed in What left this computer as Link check. It never checks addresses on this computer or its network, answers from a profile that can't use the internet, or chats using anything marked this computer only. The saved answer has `meta.link_check`, and `chat.links_checked` says when it's added (#209, contract 1.97).
