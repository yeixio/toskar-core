### Added

- A chat model can be kept running on a computer (#966, contract 1.94): `PUT /api/v1/models/{id}/always-running`. It loads when Toskar starts and again within a minute if it stops, such as after a crash, and isn't unloaded when idle or to make room for a picture or clip. A training run still frees the memory, and the model comes back after it. Stopping it yourself keeps it stopped until you start it again or Toskar starts. Turn it on in Models, under a model's More actions → Always running, or with `toskarctl models pin`. The model's card says Always running and how much memory it leaves for other models (`memory_left_bytes`, contract 1.95), and a model that then doesn't fit says which model kept running holds the memory. The Running tab and Performance mark a model kept running too (`always_running` on `GET /models/running`, contract 1.96), and only Admins see the menu item, as only they can change it. With paired computers, placement sends a model's requests to the computer keeping it running, and passes over a computer whose models kept running leave too little memory for it when another has the model.
